# 명함 스캔 챗봇 PRD

**Product Requirements Document**

작성일: 2026-06-11 | 버전: v1.0 | 상태: Draft

---

## 1. 개요

사용자가 텔레그램에 명함 사진을 업로드하면, 봇이 명함의 정보를 인식(OCR)하여 (1) 명함에 적힌 이메일 주소로 사용자 본인의 명함 이미지와 소개 문구를 자동 발송하고, (2) 인식된 명함 정보를 지정된 Google Drive 스프레드시트에 자동으로 저장하는 텔레그램 챗봇이다.

## 2. 목표 및 배경

### 2.1 문제 정의

- 오프라인에서 받은 명함을 정리하고, 상대방에게 내 명함을 다시 전달하는 과정이 번거롭다.
- 받은 명함 정보를 수기로 입력해 관리하는 데 시간이 소요되고 누락·오타가 발생한다.

### 2.2 목표

- 명함 사진 한 장으로 내 명함 전달과 연락처 데이터화를 동시에 자동 처리한다.
- 별도 앱 설치 없이 텔레그램만으로 전체 워크플로우를 완결한다.

## 3. 핵심 사용자 시나리오

1. 사용자가 텔레그램 봇 채팅방에 명함 사진을 전송한다.
2. 봇이 이미지를 OCR/Vision으로 분석해 이름, 회사, 직책, 이메일, 전화번호 등을 추출한다.
3. 봇이 추출 결과를 사용자에게 보여주고 확인을 요청한다(선택적 검수 단계).
4. 확인 후, 봇이 명함의 이메일 주소로 사용자의 명함 이미지와 소개 문구를 발송한다.
5. 동시에 추출된 명함 정보를 지정된 Google 스프레드시트에 새 행으로 추가한다.
6. 봇이 사용자에게 처리 완료(이메일 발송 성공/저장 완료)를 알린다.

## 4. 기능 요구사항

### 4.1 명함 인식

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-1 | 텔레그램으로 전송된 이미지(JPG/PNG)를 수신하고 다운로드한다. | P0 (필수) |
| FR-2 | 이미지에서 이름, 회사, 직책, 이메일, 전화번호, 주소를 추출한다. | P0 (필수) |
| FR-3 | 이메일을 인식하지 못한 경우 사용자에게 안내하고 처리를 중단한다. | P0 (필수) |
| FR-4 | 추출 결과를 사용자에게 표시하고 발송 전 확인을 받는다. | P1 (권장) |

### 4.2 이메일 발송

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-5 | 명함의 이메일 주소로 사용자의 명함 이미지를 첨부해 발송한다. | P0 (필수) |
| FR-6 | 이메일 본문에 사용자 소개 문구(템플릿)를 포함한다. | P0 (필수) |
| FR-7 | 발송 성공/실패 결과를 사용자에게 텔레그램으로 통지한다. | P0 (필수) |
| FR-8 | 소개 문구와 명함 이미지는 사용자가 사전 등록/수정할 수 있다. | P1 (권장) |

### 4.3 스프레드시트 저장

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-9 | 지정된 Google Drive 스프레드시트에 명함 정보를 새 행으로 추가한다. | P0 (필수) |
| FR-10 | 저장 항목: 이름, 회사, 직책, 이메일, 전화번호, 등록일시, 이메일 발송여부. | P0 (필수) |
| FR-11 | 중복 이메일 발견 시 중복 표시 또는 알림을 처리한다. | P2 (선택) |

## 5. 비기능 요구사항

- **성능**: 사진 업로드 후 결과 응답까지 평균 10초 이내.
- **보안**: 명함/이메일 등 개인정보는 전송·저장 시 접근 권한을 최소화하고 외부 노출을 방지한다.
- **안정성**: 이메일 발송 또는 시트 저장 실패 시 재시도 및 오류 로깅.
- **개인정보**: 수집 정보는 명함 교환 목적에 한해 사용하며 관련 규정을 준수한다.

## 6. 스프레드시트 컬럼 정의

| 컬럼 | 설명 | 예시 |
|------|------|------|
| 이름 | 명함 소유자 성명 | 홍길동 |
| 회사 | 소속 회사명 | ABC Corp |
| 직책 | 직위/부서 | 팀장 |
| 이메일 | 연락 이메일 | gd@abc.com |
| 전화번호 | 연락처 | 010-1234-5678 |
| 등록일시 | 시트 저장 시각 | 2026-06-11 14:30 |
| 발송여부 | 이메일 발송 결과 | 성공 |

## 7. 기술 구성 (제안)

- **인터페이스**: Telegram Bot API (Webhook 기반 메시지/사진 수신).
- **명함 인식**: Vision/OCR 모델 또는 외부 OCR API를 통한 텍스트 추출 및 필드 파싱.
- **이메일 발송**: SMTP 또는 메일 발송 API(예: Gmail API).
- **데이터 저장**: Google Sheets API를 통한 행 추가.
- **서버**: 봇 로직을 호스팅할 백엔드(서버리스 함수 또는 상시 서버).

## 8. 범위 외 (Out of Scope)

- 명함 정보의 CRM 시스템 연동 및 양방향 동기화.
- 다국어 명함의 고정밀 인식 및 자동 번역.
- 발송된 이메일의 회신 추적 및 자동 응답.

## 9. 성공 지표 (KPI)

- 명함 필드 인식 정확도 95% 이상(이메일 기준).
- 사진 업로드 → 이메일 발송 + 시트 저장 성공률 98% 이상.
- 처리 1건당 평균 소요 시간 10초 이내.
