# PRD: 텔레그램 딥리서치 챗봇

## 1. 개요

### 1.1 제품 목적
텔레그램 채팅창에 조사하고 싶은 주제를 입력하면, Gemini API의 내장 Google Search 그라운딩을 활용해 해당 주제를 심층 조사하고, 결과를 마크다운 문서(.md)로 로컬 PC 폴더에 자동 저장하는 개인용 리서치 자동화 도구.

### 1.2 핵심 가치
- **편의성**: 텔레그램이라는 익숙한 인터페이스로 언제 어디서나 리서치 요청
- **깊이**: Gemini의 실시간 Google Search 그라운딩으로 최신 정보 기반 심층 조사
- **단순함**: 외부 검색 API 없이 Gemini 하나로 검색·분석·작성 일괄 처리
- **정리**: 재사용 가능한 구조화된 마크다운 문서로 자동 저장

## 4. 기능 요구사항

### 4.1 핵심 기능 (MVP)

#### F1. 리서치 요청 처리
- 사용자가 주제 텍스트를 입력하면 봇이 인식
- 대화형 정제: 조사 범위·깊이·세부 관심사를 2~3개 질문으로 확인
- 질문을 건너뛰고 싶을 때: "그냥 바로 조사해줘" 명령 지원

#### F2. 정보 수집 및 문서 생성 (Gemini 단일 처리)
- Gemini API의 **Google Search 그라운딩** 기능으로 실시간 웹 검색 + 분석 + 마크다운 작성을 한 번에 처리
- 별도의 검색 API(Tavily, Wikipedia 등) 불필요
- 조사 깊이에 따라 분량 자동 조절 (간략: ~500자 / 심층: ~3000자)
- 기본 문서 구조:
  ```
  # 주제명
  > 조사일: YYYY-MM-DD

  ## 요약
  ## 배경 및 개요
  ## 핵심 내용
  ## 주요 사례/데이터
  ## 시사점 및 전망
  ## 참고 출처
  ```

#### F3. 로컬 파일 저장
- 저장 경로: `/Users/chooyeanchan/Library/Mobile Documents/iCloud~md~obsidian/Documents/chooyeanchan_icloud/1.0_llm wiki/inbox`
- 파일명 규칙: `YYMMDD 주제.md` (예: `260614 양자컴퓨터 최신동향.md`)
- 저장 완료 후 텔레그램으로 파일 경로 + 3줄 요약 알림

#### F4. 기본 명령어
| 명령어 | 동작 |
|--------|------|
| `/start` | 봇 소개 및 사용법 안내 |
| `/research [주제]` | 리서치 시작 (또는 그냥 텍스트 입력) |
| `/setpath [경로]` | 저장 폴더 경로 변경 (기본값: Obsidian inbox) |
| `/list` | 최근 저장한 파일 목록 5개 |
| `/help` | 명령어 목록 |

### 4.2 확장 기능 (v2)
- 저장된 파일을 텔레그램으로 직접 전송 (`/send [파일명]`)
- 조사 결과를 이전 파일에 이어서 추가 (`/append`)
- 정기 리서치 스케줄 등록 (예: 매주 월요일 특정 주제 자동 조사)

## 5. 비기능 요구사항

| 항목 | 목표 |
|------|------|
| 응답 시작 | 요청 후 3초 내 "조사 시작" 메시지 |
| 조사 완료 | 일반 주제 기준 30~60초 이내 |
| 가용성 | 로컬 PC가 켜져 있는 동안 상시 동작 |
| 보안 | 봇 토큰, API 키는 `.env` 파일 관리, 코드에 하드코딩 금지 |
| 사용 언어 | Python 3.11+ |

## 6. 기술 스택

| 역할 | 선택 기술 | 이유 |
|------|-----------|------|
| 텔레그램 봇 | `python-telegram-bot` v20+ | 비동기 지원, 문서 풍부 |
| 검색·분석·작성 | Gemini API `gemini-2.0-flash` + Google Search 그라운딩 | 검색/분석/작성을 하나의 API로 통합 처리 |
| 파일 저장 | Python 내장 `pathlib` | 별도 의존성 없음 |
| 설정 관리 | `python-dotenv` | API 키·경로 분리 관리 |
| 로컬 실행 | 터미널 직접 실행 또는 `launchd`/`cron` 데몬 | 상시 실행 |

## 7. 시스템 구성도

```
[텔레그램 앱] ←→ [텔레그램 서버]
                        ↓ (Polling)
              [로컬 PC - Python 봇 서버]
                   ├── 대화 관리 (ConversationHandler)
                   ├── Gemini API
                   │    ├── Google Search 그라운딩 (실시간 웹 검색)
                   │    └── 마크다운 문서 생성
                   └── 파일 저장 (로컬 ~/Documents/Research/)
```
