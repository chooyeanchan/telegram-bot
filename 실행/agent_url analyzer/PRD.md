# PRD: URL 요약 텔레그램 챗봇

## 개요

텔레그램 채팅에서 URL을 입력하면 해당 콘텐츠(유튜브, 블로그, 뉴스 등)를 자동으로 분석·요약하여 마크다운 파일로 만든 뒤 iCloud Drive 지정 폴더에 저장하는 개인용 챗봇.

---

## 목표

- URL 하나를 보내는 것만으로 콘텐츠 소비 없이 핵심 내용을 확보한다.
- 저장된 마크다운은 Obsidian, Bear 등 어떤 노트 앱에서도 바로 열 수 있어야 한다.
- 운영 비용을 최소화한다 (서버리스 또는 경량 로컬 실행).

---

## 사용자 시나리오

1. 사용자가 텔레그램에서 봇에게 URL을 전송한다.
2. 봇이 "처리 중..." 메시지를 즉시 보낸다.
3. 봇이 URL 유형을 판별하고 콘텐츠를 수집한다.
4. Claude API로 요약·분석을 생성한다.
5. 마크다운 파일을 iCloud Drive 지정 폴더에 저장한다.
6. 봇이 요약 미리보기(300자 이내)와 저장 경로를 텔레그램으로 회신한다.

## 지원 URL 유형

| 유형 | 수집 방법 |
|------|-----------|
| 유튜브 | `youtube-transcript-api` 로 자막 추출 |
| 일반 웹페이지 (블로그·뉴스) | `trafilatura` 또는 `newspaper4k` 로 본문 추출 |
| PDF (직접 링크) | `pdfplumber` 로 텍스트 추출 |
| 트위터/X | `snscrape` 또는 공개 임베드 파싱 |
| 지원 불가 | 안내 메시지 반환 |

## 마크다운 파일 템플릿

```markdown
---
title: {{제목}}
url: {{원본 URL}}
type: {{youtube | blog | news | pdf | other}}
date: {{저장 일시 YYYY-MM-DD HH:mm}}
tags: [{{자동 태그}}]
---

## 요약

{{3-5문장 핵심 요약}}

## 핵심 포인트

- {{포인트 1}}
- {{포인트 2}}
- {{포인트 3}}

## 주요 인용

> {{원문에서 중요한 문장}}

## 원문 링크

{{URL}}
```

파일명 규칙: `YYYYMMDD_HHMMSS_{{슬러그}}.md`
예) `20260610_143022_llm-agents-2026.md`
