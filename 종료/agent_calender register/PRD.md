# 텔레그램 캘린더 등록 챗봇 PRD

> 작성일: 2026-06-14 | 버전: v1.0

---

## 개요

텔레그램에서 일정을 말하면 Google Calendar에 자동 등록해주는 개인용 챗봇.

---

## 목표

- 텔레그램 대화창에서 앱 전환 없이 일정 등록
- 자연어로 자유롭게 입력 → AI가 파싱 → 캘린더에 저장
- 등록 후 확인 메시지 + 캘린더 링크 수신

---

## 핵심 기능

### 1. 자연어 일정 파싱 (Claude API)

- 날짜/시간: `내일 오후 3시`, `다음 주 월요일`, `6월 20일 10:00`
- 제목, 장소, 반복 패턴 추출
- 불명확한 정보는 되묻기

### 2. Google Calendar 등록

- OAuth 2.0 연동
- 이벤트 생성 (제목, 날짜/시간, 장소, 설명)
- 등록 후 이벤트 링크 반환

### 3. 등록 확인 메시지

- 파싱된 정보 요약 표시
- 수정 / 삭제 버튼 제공

### 4. 명령어

| 명령어 | 기능 |
|--------|------|
| `/start` | 시작 및 Google 계정 연동 |
| `/오늘` | 오늘 일정 조회 |
| `/이번주` | 이번 주 일정 조회 |
| `/disconnect` | 계정 연동 해제 |
| 자유 텍스트 | 일정 등록 |

## 기술 스택

| 항목 | 선택 |
|------|------|
| 언어 | Python 3.11+ |
| 봇 | python-telegram-bot v20+ |
| AI 파싱 | Gemini API (`gemini-2.0-flash`) |
| 캘린더 | Google Calendar API |
| 서버 | FastAPI + Webhook |
| DB | SQLite (개인용이라 간단하게) |
| 배포 | Railway 또는 로컬 서버 |

---

## 데이터 흐름

```
텔레그램 메시지 입력
    ↓
Webhook → FastAPI 서버 수신
    ↓
Gemini API로 자연어 파싱 (JSON 추출)
    ↓
Google Calendar API로 이벤트 생성
    ↓
챗봇이 확인 메시지 + 링크 전송
```

---

## AI 파싱 출력 포맷

```json
{
  "title": "팀 미팅",
  "start_datetime": "2026-06-15T15:00:00",
  "end_datetime": "2026-06-15T16:00:00",
  "location": null,
  "description": null,
  "recurrence": null
}
```

---

## 파싱 예시

| 입력 | 결과 |
|------|------|
| `내일 오후 3시 팀 미팅` | 팀 미팅 / 내일 15:00 |
| `6/20 10시 강남역 고객 미팅` | 고객 미팅 / 06-20 10:00 / 강남역 |
| `매주 월요일 9시 스탠드업` | 스탠드업 / 매주 월 09:00 |
| `금요일 저녁 7시 홍대 약속` | 약속 / 금 19:00 / 홍대 |
