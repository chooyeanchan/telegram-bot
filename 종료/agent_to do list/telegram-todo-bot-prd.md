# PRD: 텔레그램 TODO 챗봇

## 1. 개요

Obsidian 볼트의 체크박스 기반 마크다운 파일에서 미완료 항목을 조회하고, 텔레그램 챗봇으로 완료 처리할 수 있는 시스템.

---

## 2. 배경 및 목적

- 현재 `1.1_tasks` 폴더에 3개의 마크다운 파일로 TODO를 관리 중
- Obsidian을 열지 않고도 모바일(텔레그램)에서 빠르게 할 일 확인 및 완료 처리 가능하게 함
- iCloud 동기화를 통해 파일 변경 사항이 Obsidian에 자동 반영됨

---

## 3. 대상 파일

| 파일명 | 설명 |
|---|---|
| `1_to do list.md` | 일반 할 일 목록 |
| `2_health check.md` | 월별 건강/생활 체크리스트 |
| `3_deep clean.md` | 분기별 대청소 체크리스트 |

---

## 4. 기능 요구사항

### 4.1 핵심 기능

#### F1. 미완료 항목 조회
- `/todo` — `1_to do list.md`의 미완료(`- [ ]`) 항목 목록 출력
- `/health` — `2_health check.md`의 미완료 항목 목록 출력
- `/clean` — `3_deep clean.md`의 미완료 항목 목록 출력
- `/all` — 3개 파일 전체 미완료 항목을 파일별로 구분하여 출력

#### F2. 항목 완료 처리
- 조회 결과에 각 항목에 번호를 부여하여 출력
- 사용자가 번호를 입력하면 해당 항목의 `- [ ]`를 `- [x]`로 변경
- 변경 후 "완료 처리됐어요: [항목명]" 응답
- 다중 번호 입력 지원 (예: `1 3 5`)

#### F3. 진행률 요약
- `/status` — 각 파일별 완료/전체 개수와 퍼센트 요약 출력
  ```
  📋 To Do: 12/28 (43%)
  🏥 Health: 32/37 (87%)
  🧹 Deep Clean: 41/56 (73%)
  ```

#### F4. AI 요약 (선택, Gemini API 사용)
- `/summary` — 미완료 항목들을 Gemini API로 분석하여 우선순위 추천
- 예: "오늘 처리하면 좋을 것 같은 항목 3개를 추천해드릴게요"

### 4.2 보조 기능

- `/help` — 사용 가능한 명령어 목록 출력
- 잘못된 번호 입력 시 오류 안내
- 인증: 챗봇을 본인만 사용할 수 있도록 `ALLOWED_CHAT_ID` 환경변수로 제한

## 5. 기술 스택

| 항목 | 선택 |
|---|---|
| 언어 | Python 3.11+ |
| 텔레그램 라이브러리 | `python-telegram-bot` v21 |
| 파일 접근 | 로컬 파일시스템 (iCloud 마운트 경로) |
| AI 요약 | Gemini API (`google-generativeai`) — 선택적 |
| 실행 환경 | 맥 로컬 (상시 실행) 또는 서버 |
| 스케줄러 | `launchd` (macOS) 또는 `systemd` |

## 6. 시스템 구조

```
telegram-todo-bot/
├── bot.py              # 메인 봇 실행 파일
├── parser.py           # 마크다운 파싱 및 체크박스 수정
├── config.py           # 환경변수 로드 (TOKEN, CHAT_ID, 파일 경로 등)
├── gemini.py           # Gemini API 연동 (선택)
├── .env                # 시크릿 (git 제외)
└── requirements.txt
```

### 파일 파싱 로직

```
- [ ] 항목  →  미완료 (조회 대상)
- [x] 항목  →  완료 (제외)
들여쓰기     →  하위 항목으로 구분 (부모 항목명과 함께 표시)
```

하위 항목 표시 예시:
```
3. AI 개발 > 옵시디언, 네이버 블로그 업로드, 메일 api
4. AI 개발 > 맛집봇에 네이버 블로그 리뷰 추가하기
```

봇: ✅ 완료 처리됐어요: 가계부 정리하기

사용자: 1 3

  ✅ 브런치에서 글감 가져오기
  ✅ 실루엣안경 구매

## 9. 구현 단계

| 단계 | 내용 | 우선순위 |
|---|---|---|
| 1 | 마크다운 파서 + 체크박스 토글 | 필수 |
| 2 | 텔레그램 봇 기본 명령어 (조회, 완료) | 필수 |
| 3 | `/status` 진행률 요약 | 권장 |
| 4 | macOS launchd로 상시 실행 등록 | 권장 |
| 5 | Gemini AI 우선순위 추천 `/summary` | 선택 |

## 10. 비기능 요구사항

- 파일 쓰기 시 원자적 저장 (임시 파일 후 rename)으로 데이터 손상 방지
- iCloud 동기화 지연 고려: 파일 변경 직후 Obsidian 반영에 수 초 소요될 수 있음
- 단일 사용자 전용 (멀티유저 불필요)
- 하위 항목 완료 시 부모 항목 자동 완료 처리는 V2에서 검토
